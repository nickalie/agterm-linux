# Linux v0.24.0 catch-up

## Range

- Previous Linux parity base: upstream `v0.23.0` (`33b60af`)
- Target parity base: upstream `v0.24.0` (`834b74a`), a tag-bounded base
- `upstream/master` carries 22 post-tag commits that are deliberately excluded
- Integration branch: `linux-port`
- Merge commit: `1a617b3` (`chore(upstream): merge upstream v0.24.0`)

## Inventory

### Portable core and shared artifacts, inherited unchanged

- `WorkspaceNavigation`, `WorkspaceStep`, `AppStore.navigateWorkspace`, `canStepWorkspaces`,
  `isCurrentWorkspaceCollapsed`, `noteSidebarExpansion`, and `selectWorkspace`'s `WorkspaceStep?` return.
- `tree`'s `activeWorkspaceID` now derived from `currentWorkspaceID` rather than the selection's owner.
- `workspace.go`, `surface.cursor`, `session.overlay.copy`, `session.overlay.text` in `ControlProtocol`,
  `ControlDispatcher`, and the `agtermctlKit` subcommands; `ControlCursor` and its bare-column CLI shaping.
- `BuiltinAction.previousWorkspace`/`.nextWorkspace`/`.toggleWorkspaceCollapse` and their palette catalog
  rows, enablement, and dynamic Collapse/Expand Workspace title.
- Keymap built-in override collisions made order-independent (#444).
- `TerminalZoomSurface.surface(in:)`.
- Cookbook `container-agent-status`, backlog notes, and the bundled skill.

### Carried portable core fix

- `QuitReason` reaches `NSAppleEventDescriptor`/`kAEQuitReason`, which exist only in Darwin Foundation, so
  the host-free package stopped building on Linux. The AppleEvent entry point and its tests are guarded with
  `#if canImport(Darwin)`, the idiom `agtermctlKit/SocketClient.swift` already uses; the type-code half stays
  shared. Upstreamable as-is.

### GTK parity work

1. `workspace.go` — `AppController.goWorkspace`, the Linux dispatcher arm, and `ControlServer` routing.
2. `surface.cursor` — `GhosttySurface.readCursorColumn`, `AppController.readSurfaceCursor`, routing.
3. `session.overlay.copy` / `.text` — overlay-surface resolution shared by both arms, plus routing.
4. Workspace navigation and per-workspace collapse — `KeymapDispatch` arms and Linux palette rows.
5. `PaletteContext` gains `activeWorkspaceCollapsed` and `canStepWorkspaces` at the Linux construction site.
6. The Linux sidebar reports what it rendered expanded through `store.noteSidebarExpansion`, without which
   `isCurrentWorkspaceCollapsed` reads every workspace collapsed while the sidebar is visible.
7. Zoom target resolution keeps `.quick` on the Linux side (see the exemption below).
8. `LinuxControlDispatcher` claims the four new commands; without that they fall through to
   `AppControllerControl`'s default and answer `command not yet supported on Linux`. Its `session.text`
   extent validation moves into a shared `parseBufferExtent`, as upstream's did.

### Linux gaps the v0.24.0 contract exposed

- `session.text` resolved its default pane through `searchTargetSurface`, which follows a program overlay,
  so it read the COVERING surface. Upstream addresses the pane underneath — that asymmetry is the whole
  reason `session.overlay.text` exists — so the arm now takes a new `onScreenSurface(for:)` carrying
  `Session.onScreenSurface`'s pane-vs-scratch rule. `session.copy` already used a pane and needed nothing.
- `workspace.select` selected the target's first session directly instead of going through
  `AppStore.selectWorkspace`, so an EMPTY target never became current. v0.24.0 derives `tree`'s active
  workspace from `currentWorkspaceID`, which makes that visible, and `workspace.go` routes through the same
  store call, so both now share `applyWorkspaceStep(from:)` for the window-level half.

### Platform-specific adaptations and exemptions

- The detached quick-terminal panel with a global hotkey (#441) stays macOS-only. It is an `NSPanel` plus a
  Carbon `RegisterEventHotKey` registration; on Wayland a system-wide hotkey needs the
  `org.freedesktop.portal.GlobalShortcuts` portal and an always-on-top detached panel needs layer-shell, so
  neither has a GTK equivalent to port. The Linux quick terminal remains the window-level drop-down card it
  already was.
- Because that panel is app-global upstream, core dropped `.quick` from
  `TerminalZoomController.resolveTarget`/`isTargetValid` and `AGTERM_WINDOW_ID` from
  `SurfaceEnvironment.quickTerminal`. The Linux panel is still owned by one window, so the app target keeps
  both: `AppController.resolveZoomTarget`/`isZoomTargetValid` prefer a visible quick panel, and the quick
  shell keeps `AGTERM_WINDOW_ID` so `--window "$AGTERM_WINDOW_ID"` from inside it keeps resolving its own
  window. Core is untouched.
- `keyCode(forChordKey:)` (#441) maps macOS virtual key codes for `RegisterEventHotKey`. It compiles on
  Linux and stays unused there.
- Debug/Release entitlement pinning (#450), `kAEQuitReason` reading, dropping libghostty's `CALayer` on
  teardown, `GHOSTTY_REV` advancing past the macOS renderer pin, and the XCUITest screenshot/`os.Logger`
  changes are all macOS build, AppKit, or Xcode-test mechanics with no Linux counterpart. The Linux CI job
  set has no macOS build job at all, which is why the upstream `ci.yml` entitlement steps were resolved out.
- `QuitReason.isSystemQuit` has no Linux caller: a logind shutdown does not deliver an AppleEvent, and
  wiring the session-manager equivalent is not part of this catch-up.

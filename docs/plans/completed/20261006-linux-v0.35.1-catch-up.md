### Fixed on the way

- A bare modifier press abandoned a half-typed leader, so no `ctrl+a>ctrl+x` sequence ever fired on Linux.
- The Linux overlay dispatcher dropped `--chromeless` and `--persistent` and refused neither misuse.

### Linux adaptations

- The GTK control path is synchronous: `browser clear` and `session restart` spin the main loop while they wait,
  as `session type`'s realize poll does, instead of suspending.
- The saved browser store is a WebKitGTK network session under `${XDG_DATA_HOME}/agterm/browser/<profile id>`;
  the plugin ABI moved to 3 for the storage directory and `clear_storage`.
- Resume is logind's `PrepareForSleep(false)` on the system bus, the network trigger `GNetworkMonitor`.
- The process table is `/proc/<pid>/stat`, start time in clock ticks since boot.
- An undetected OpenCode version installs OpenCode 1's plugin, where macOS asks: the plan-based installer has
  no dialog. `verify-linux-packages.sh` checks the bundled v2 plugin.
- A dashboard's covered cell names the overlay in a GTK box over the paintable; a page's title change refreshes it.
- `session restart` has no AT-SPI case: Live needs zsh as the account's login shell. It was exercised by hand in
  the build container with root's shell set to zsh: two restarts kept the pane id, the old `sleep` ended, and
  closing the pane hung up its foreground job.

### macOS-only, exempt

- Stock macOS menu chords (#680): GTK has no stock menu shortcuts a `map` line could collide with.
- Split ratio re-applied on length change (#692): `GtkPaned` scales its position with the allocation.
- Off-screen HTML page taking file drops (#685): an unmapped GTK widget is not a drop target.
- Auto-hidden sidebar after Reopen from the quick terminal: an AppKit window-ordering path.
- Debug launches adopting `agterm-debug` (`DebugStateDirectory`): the Linux build has no Debug bundle identity.
- Hidden windows releasing their panes' GPU surfaces (fc817f4b): a Metal swap-chain release; README already
  records that hidden Linux panes keep their GL renderers.
- Overlay wrapper as a non-login `/bin/sh`: the GTK host runs the wrapper with `sh -c`, never through `login`.

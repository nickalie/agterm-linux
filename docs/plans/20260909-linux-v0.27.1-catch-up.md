- Previous Linux parity base: upstream `v0.26.0` (`24bed8b`)

## Merge conflicts and how they were resolved

- `README.md` — downstream replaced upstream's `agtermctl` demo block with the Linux CLI build and the
  `integration` commands. Upstream only added an `ask` line to that demo, so the downstream text stands.
- `agterm/Resources/agent-status/agterm-codex-status.sh` — downstream reads
  `last_assistant_message` through plutil, python3 or jq because Linux has no plutil. Upstream replaced the
  naive `*"?"*` test with a fenced-code/span-aware one. Kept the portable extraction, took the new heuristic.
- `agtermCore/Sources/agtermctlKit/Commands.swift` — downstream factored the root into
  `AgtermctlCommandCatalog`; upstream appended `Ask.self` to its literal list. Added `Ask.self` to the catalog.
- `plugins/agterm/skills/agterm/SKILL.md` — upstream rewrote the description to fit the 1536-character
  listing cap. Took the new text and reapplied the two downstream platform edits.

## Inventory

### Portable core and shared artifacts, inherited unchanged

- The whole `ask` decision layer: `Ask.swift` (`PendingAsk`, `AskAnchor`, `AskRegistry`, `AskNavigation`),
  `ControlAsk.swift`, `ControlDispatcher+Ask.swift` and its validation, `agtermctlKit/AskCommands.swift`.
- `ControlDispatcher+Panes.swift`, the pane parsers upstream split out, and `StatusPane`/`OverlayPane`
  parsing of the documented aliases.
- `ControlAskPlacement`, `ControlHudPlacement`, and the `ControlActionsDefaults` overloads upstream added so
  this fork keeps building before it adopts them.
- `ControlProjection`: `ControlSessionAsk`, `ControlHudNode.pane`, `ControlTree.askPending`.
- `Session` ask slot and `hudPaneIdentity`/`hudTargetPane`/`paneRole(forIdentity:)`; `AppStore` cancelling a
  pending ask on session and workspace close.
- `PaletteCatalog`'s widened `pickerActive`, `Pick` refactor, cookbook recipes, backlog notes, upstream plans.

### GTK parity work

1. `StatusPane` adoption through the Linux adapter — `session.type`, `session.text`, `font`, and the surface
   maps that still switch on raw `"left"`/`"right"`/`"scratch"` strings.
2. `session.paste --pane` (#529) — `pasteSession(_:window:pane:)` writing the addressed pane.
3. `session.hud --pane`/`--pane-id` (#536, #545) — the `ControlHudPlacement` overloads, the resolved pane
   identity stored on the session, anchors and `--size-percent` measured against that pane's live bounds,
   and `hud.pane` on the tree.
4. `ask` (#556, #561) — `ask.open`/`ask.result`/`ask.cancel` routing, a GTK dialog in both styles, session
   ownership and pane scoping for `terminal`, window-modal for `gui` sharing the pending slot with `pick`,
   `AskRegistry.resolveOwner` wiring, keyboard handling through `AskNavigation`, `askPending` on the tree,
   and `pickerActive` in the palette context.
5. `fix(zmx)` (#533) — a fresh live pane's `--command` goes to zmx as a create-only argv payload instead of
   through `initial_input`, and a fresh split pane gets one at all.
6. `fix(sessions)` (#544) — drop a terminal title equal to the pane's own cwd. The Linux port never carried
   the arming guard this replaces, so it takes the new comparison directly.
7. `fix` (`fc14cbb`) — read the cursor column from the IME point's cell height instead of the widget's scale
   factor, so a hidden pane reads without being realized.
8. `fix(focus)` (#562) — keep a retired surface from reclaiming keyboard focus after its session closed.

### Latent Linux defects the parity work uncovered

- `session.hud.*` reached no dispatcher. The host half landed with the panel, but the validation it
  expected is internal to `agtermCore`'s dispatcher, which this fork does not run, so every call answered
  `command not yet supported on Linux`. Fixed with the pane-scoping work, which needs a live route.
- The overlay never exported `AGTERM_HUD_FILE`, so a panel exited the moment it started.
- `projectingLinuxAutoFollow` rebuilt the tree field by field and dropped `sidebarWidth`,
  `workspaceFilter`, `pickPending`, `askPending`, `app`, and the window node's `minimized`.
- `session.status` and `session.restore` parsed `--pane` through `rawValue`, refusing the documented
  aliases the same way #530 describes for the surface commands.

### macOS-only, exempt

- #537 `NSAppDataUsageDescription` and the App Data permission documentation: a TCC mechanism with no Linux
  counterpart.
- #542 and #546, the split divider re-applied against a stale safe-area inset: agterm-linux has no
  safe-area inset and its GTK paned divider is not laid out through a titlebar band.
- #547 and #548, SwiftUI invalidation on an OSC 2 title tick: the Linux sidebar row is a `GtkListView` cell
  updated in place already, and no view graph re-runs on a title change.
- #555 `selectedRange` reporting an empty caret for system Dictation: an `NSTextInputClient` contract.

`agtermCore`'s `CodexStatusHookTests` flakes under a loaded container: a different case fails each time,
including watcher cases that never reach the hook's message parsing, and twelve isolated runs of the
suite pass against both the merged script and upstream's own. It is a property of those upstream tests
here, not of the merge resolution.

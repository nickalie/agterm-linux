# Linux v0.32.0 catch-up

## Range

- Previous Linux parity base: upstream `v0.29.1` (`ecee06e`)
- Target parity base: upstream `v0.32.0` (`1ffc3ee`), covering `v0.30.0`, `v0.30.1`, `v0.31.0` and `v0.32.0`
- `upstream/master` carries one post-tag commit, `474d504` (site home page copy), deliberately excluded
- Integration branch: `linux-port`
- Merge commit: `4031fc4` (`chore(upstream): merge upstream v0.32.0`)
- `GHOSTTY_REV` is unchanged; `ZMX_REV` moves to v0.8.1 (`8bab1f0`) plus `scripts/zmx-patches`

## Merge conflicts and how they were resolved

- `.github/workflows/ci.yml` — kept the Linux job, moved the upstream pin to `v0.32.0`.
- `AppSettings.swift` — the fork's `sessionNameFromTerminalTitle` and upstream's `flaggedViewLayout` both kept.
- `AppStore+PendingClose.swift` — upstream's `closeTimedHud` beside the fork's `MainTimer` grace timer.
- `AppStore+Status.swift` — upstream's shared `attentionPrecedes` order, filtered on the fork's
  `AgentStatus.needsAttention` (`ab2eff0`), so the cross-window list inherits the narrowing.
- `Session.swift` — upstream moved context validation to `SessionContext.swift` as internal API;
  the Linux dispatcher calls it, so `SessionContextValidation` and `validateContext` stay `public`.
- `agtermctlKit/Commands.swift` — the fork's `AgtermctlCommandCatalog` gains `Hooks` and `Terminfo`.
- `agterm/agtermApp.swift` — upstream's remote-presentation guard in front of the fork's `afterKeystroke`.
- Docs, rules and the bundled skill — upstream's cross-window wording with the fork's attention filter and
  the Linux `ctrl+,` reservation; the skill description stays under 1024 characters (1020).

## Carried core deltas added by this catch-up

- `TerminfoInstall`, `OverlayRunJob`: glibc `posix_spawn` types; `addclosefrom_np` for CLOEXEC_DEFAULT;
  a self-stopping shell in place of `POSIX_SPAWN_START_SUSPENDED`; `SIGPIPE` ignored in place of
  `F_SETNOSIGPIPE`.
- `ZmxLead.swift`: `import Observation`, which Darwin gets transitively.
- `HudMarkdown+Portable*.swift`: Foundation's markdown parser is Darwin-only, so Linux parses HUD markdown
  with its own CommonMark/GFM block and inline parser that feeds the same `Line` model; upstream's
  `HudMarkdownTests` are the contract.
- Test portability: `SocketPortability.swift` and `import Observation` in two suites.

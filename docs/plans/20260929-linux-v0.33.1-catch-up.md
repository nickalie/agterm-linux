  - a C plugin `libagterm-webkit.so` linked against `webkitgtk-6.0`, reached through `dlopen` and one

- [ ] 5. Packaging: `libwebkitgtk-6.0-dev` in CI and release builds, the plugin in tar/DEB/RPM/Flatpak,
      `Recommends` in DEB/RPM, no plugin in the AppImage, closure checks aware of the optional plugin.

### Linux adaptations

- Show in Finder is Show in Files: `org.freedesktop.FileManager1.ShowItems`, the folder as a fallback.
  The protocol keeps `navigate finder`.
- The AppImage ships no WebKitGTK: its helper processes are not relocatable, so HTML overlays refuse there.
- A missing WebKitGTK refuses the open with an install hint instead of an empty panel.

### macOS-only, exempt

- `NSAllowsLocalNetworking`: WebKitGTK has no App Transport Security.
- `WindowAccessor`, `WorkspaceSidebar` and `AskDialogView` AppKit adjustments carry no Linux counterpart
  beyond the cover-aware focus of item 4.
- Reset Live Sessions itself remains unported (existing exemption); only the `outdated` read-back lands.

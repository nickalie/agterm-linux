## The status seam

Upstream #585 added `StatusReset` (`firstKey`/`enter`/`never`) and reworked `AgentIndicator.clearedBy`.
This fork carries `a98910a` and `ab2eff0`, which answer a `blocked` prompt into `active` instead of idle.
The two designs occupy the same function.

Resolution: upstream's mode gate decides WHETHER a `blocked` or `completed` glyph moves at all — the exact
upstream truth table, `StatusReset.moves(_:)` — and where it opens, the fork's landing state stands, so an
answered block still becomes blinking `active`. `active` still clears on an interrupt in every mode. The
API is `AgentStatus.afterKeystroke(keystroke:reset:)` and
`AgentIndicator.afterKeystroke(pane:keystroke:reset:)`.

### macOS-only, exempt

- #574 the session host and `AgtermResponsibility`: the whole feature repairs a macOS TCC identity, which
  has no Linux counterpart. Upstream already guards the targets with `#if os(macOS)`.
- #587 and `3c91481` Reset Live Sessions: it exists to replace panes that lost that macOS identity.
  Linux keeps the shared `zmx.reset` routing, which answers the default refusal.
- #578 the session-host test client, and `c0b5a85` the Homebrew cask seed.
- #579/#580 status sounds off the main thread: the Linux player is `gdk_display_beep`, with no name
  lookup and no sound file to read, so neither the lookup nor the playback the fix moves exists here.
- `f81b4db` a flagged no-op rename stripping the workspace tail: `commitInlineRename` rebuilds the sidebar
  whatever the text did, and the rebuilt row takes `LinuxSidebarPolicy.flaggedRowLabel` with its tail.
- `9416408` `window list` naming a stale active window: the list is built from live state on every call
  here, not from a cache a reveal has to invalidate.

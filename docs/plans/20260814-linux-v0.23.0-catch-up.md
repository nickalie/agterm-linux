## Inventory

### Portable core and shared artifacts, inherited unchanged

- `SplitAxis`, `Session.splitAxis`, `AppStore.setSplitVisibility`, snapshot and tree read-back.
- `session.split --axis`, `session.split.close`, and their `agtermctl` subcommands in `agtermctlKit`.
- `BuiltinAction.toggleHorizontalSplit` and the `Cmd-Shift-D` → `Cmd-Shift-G` Dashboard chord migration
  with its keymap compatibility guard.
- Keymap `|` alternatives: parser, per-alternative validation, `KeybindMatcher`, and `keymap.list`
  read-back.
- `PaletteCatalog`'s Close Split row (macOS builds its palette from the catalog; Linux does not).
- Agent-hooks alert text, `AgentHooksInstall` merge policy, cookbook recipes, backlog notes, and the
  bundled skill.

### GTK parity work

1. `session.split.close` — `AppController.closeSessionSplit`, the Linux dispatcher arm, and the
   `ControlServer` session-routing arm.
2. Horizontal split — orient the session `GtkPaned` from `Session.splitAxis`, transpose a live split
   without replacing either surface, honor `session.split --axis`, and keep the divider ratio meaning the
   primary pane's fraction on both axes.
3. `toggleHorizontalSplit` — a Linux chord in `LinuxKeyboardPolicy` and a `KeymapDispatch` arm.
4. Keymap alternatives — handle `KeybindMatcher`'s `.firedBuiltin` outcome in `KeymapDispatch`.
5. Palette — a Close Split row and a Split Horizontally row in the Linux palette, gated like macOS.
6. Pane vocabulary — sidebar, titlebar, and context-menu strings that name left/right follow the axis.
7. `session not realized` from Linux `session.copy`/`paste`/`selectall`.

### Platform-specific adaptations and exemptions

- `SystemWakeObserver` (#417) is `NSWorkspace.didWakeNotification`. GTK/Wayland exposes no equivalent
  display-wake signal, and the Linux surface path realizes from GTK layout rather than an AppKit retry
  ladder, so the observer stays macOS-only.
- `NSAudioCaptureUsageDescription` (#432) is an `Info.plist` entitlement string with no Linux analogue.
- The agent-hooks alert fix (#430) is `NSAlert` sizing. Linux presents the same information through
  Preferences ▸ Integrations, which scrolls, so no Linux change is required.
- `ControlServer`'s `flock` ownership refusal (#418) is already Linux behavior through the fork's own
  `ControlServer`; verify rather than port.
- The macOS `Cmd-Shift-G` Dashboard chord does not reach Linux, which keeps `Ctrl-Shift-M` and therefore
  never needed `Cmd-Shift-D` freed. The Linux horizontal-split chord is chosen independently.

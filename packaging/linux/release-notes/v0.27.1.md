### Linux adaptations

- The `ask` dialog is native in both styles. `--style terminal` draws inside the deck in the terminal
  theme's own colors and monospace face, clipped to the anchored pane, and claims the keyboard only while
  that pane is focused, so a split's other pane keeps typing. `--style gui` is a transient modal window
  with ordinary GTK buttons rather than a drawn material panel; there is no Command-W, so Esc and the
  window's own close both answer `escaped`. Return, Tab, the arrows and the letter hotkeys behave as
  upstream's do, and both styles read back on the tree.
- `session.hud` works for the first time on Linux. The host had landed with the panel, but its validation
  is internal to the shared dispatcher this fork does not run, so every call answered
  `command not yet supported on Linux`, and the panel's painter was never given the body file it re-reads,
  so it would have exited at once. Both are fixed, and `--pane`/`--pane-id` scope the panel to one pane's
  live bounds through `gtk_widget_compute_bounds`.
- `session.paste --pane` and the documented `primary`/`split`/`top`/`bottom` aliases now resolve. The
  aliases were accepted by the shared CLI and then refused by the Linux host, on `session.status` and
  `session.restore` as well as the surface commands upstream fixed.
- `tree` and `window list` stopped losing fields. The auto-follow projection rebuilt both node types field
  by field to substitute one window's timeout, silently dropping `sidebarWidth`, `workspaceFilter`,
  `pickPending`, `askPending`, `app` and a window's `minimized`.
- The live-session command fix, the OSC 7 synthetic-title guard, and the hidden-pane cursor read are all
  ported as upstream wrote them.

### Not carried from upstream

- The repeating "access data from other apps" prompt and its `NSAppDataUsageDescription` wording: a macOS
  TCC mechanism with no Linux counterpart.
- The restored split laid out against a stale safe-area inset, and the top pane drawn under a compact
  titlebar on macOS 27: the GTK paned divider is not laid out through a titlebar band and there is no
  safe-area inset here.
- The SwiftUI invalidation an OSC 2 title storm caused: the Linux sidebar row is a `GtkListView` cell
  updated in place already, and no view graph re-runs on a title change. Covered by an AT-SPI case.
- The empty caret reported for system Dictation: an `NSTextInputClient` contract.
- Hidden panes releasing their GPU buffers: this fork pins its own libghostty with local patches, and its
  deck deliberately keeps a stable `GtkGLArea` per session so Dashboard can mirror live surfaces without
  reparenting one.

Live sessions need zsh as the account's login shell, as upstream does. Remote sessions additionally need
key-based ssh, `agtermctl` on the PATH sshd gives a remote command, and agterm in Live sessions mode on
the far side.

Compatible with Ubuntu 24.04 / Debian 13 or newer and modern Fedora systems with glibc 2.39 or newer.
All artifacts are x86_64; the AppImage additionally bundles GTK4 and libadwaita.

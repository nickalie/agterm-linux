### Linux adaptations

- Live sessions run on the same pinned zmx, built for Linux and shipped at `libexec/zmx` in every artifact.
  The pane's foreground is resolved through the daemon's pty foreground group in `/proc`, so `tree` reports
  what is running rather than the attach client, and the launch reap, the pane claims and the quit-time
  capture behave as they do upstream.
- Remote sessions work the same way over ssh. `zmx.tree` and `zmx.attach` run on a worker thread of their
  own: GLib drives the main loop and drains no Swift Concurrency executor, and handling them inline would
  deadlock `zmx tree <this machine>` against the connection it is holding.
- `session.swap` moves the two pane hosts between the paned's slots, never the `GtkGLArea`s they wrap, and
  holds a reference across the reparent.
- `session.context` composes both title-bar rows through the shared host-free composer, so compact mode
  shows the context too; the toggle joins Preferences ▸ Interface with the rest of the chrome.
- The quick terminal's panel size is a share of the WINDOW rather than the screen — the Linux panel belongs
  to its window — and Default keeps the fixed insets the card shipped with.
- `sidebar.width`, `restore.capture`, `version`, cursor shape and blink, the truncated-name hover reveal,
  the launch spawn queue, and forcing `ssh-env`/`ssh-terminfo` off all match upstream.
- The Claude status adapter installs with the rest of the agent-status package and knows the Linux
  executable names when it walks the process chain to decide who owns a pane.

Hidden panes keep their GPU renderers. Upstream frees a hidden pane's Metal swap chain behind a libghostty
pin bump this fork does not take: it pins its own libghostty with three local patches, and its terminal
deck deliberately keeps a stable `GtkGLArea` per session so Dashboard can mirror live surfaces without
reparenting one.

Live sessions need zsh as the account's login shell, as upstream does. Remote sessions additionally need
key-based ssh, `agtermctl` on the PATH sshd gives a remote command, and agterm 0.26.0 in Live sessions mode
on the far side.

Compatible with Ubuntu 24.04 / Debian 13 or newer and modern Fedora systems with glibc 2.39 or newer.
All artifacts are x86_64; the AppImage additionally bundles GTK4 and libadwaita.
